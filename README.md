# 🤖 CraftGemini (Minecraft Gemini AI Integration)

A custom Spigot / Paper plugin that integrates Google's Gemini AI directly into Minecraft chat. Players can ask questions and interact with the AI in real-time using the `/yz` in-game command.

## 🚀 Features

- ⚡ **Powered by Gemini 2.5 Flash:** Fast, smart, and optimized response generation.
- 💬 **In-Game Command:** Simply use `/yz <your message>` to talk to the AI.
- 🛠️ **Lightweight & Clean:** Optimized async tasks to prevent server lag.

---

## 🔑 How to Get a Gemini API Key

1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Log in with your Google account.
3. Click on **"Get API key"** and create a new key.
4. Copy the key and paste it into the plugin's `config.yml` file.

---

## 🔧 Installation & Usage

1. Download the compiled `.jar` file (`yapayzeka10.8t.jar`) and place it into your server's `plugins/` folder.
2. Enter your **Gemini API Key** in `plugins/CraftGemini/config.yml`.
3. (Optional) Make sure the target model is set to `gemini-2.5-flash` in the config file.
4. Start/Reload your Spigot/Paper server (**Minecraft 1.20.4+**).
5. Run `/yz <message>` in-game and enjoy!

---

## 📜 Requirements
- **Minecraft:** 1.20.4 (Spigot / Paper)
- **Java:** 21+
